====================================================================
         HeavenOS - HOW TO RUN (SAME STEPS AS how to start up.txt)
====================================================================

NOTE: Ye poora setup Google Cloud Shell ke cloud server pe chalega.
Apne local PC pe koi heavy file ya OS download karne ki zaroorat nahi hai.
HeavenOS = Arch Linux XFCE (LinuxServer Webtop) with custom branding.

--------------------------------------------------------------------
STEP 1: GOOGLE CLOUD SHELL OPEN KARO
--------------------------------------------------------------------
1. Browser me open karo: https://console.cloud.google.com/
2. Apna Google Account login karo.
3. Top-right bar me ">_" (Activate Cloud Shell) icon par click karo.
4. Neeche ek Linux terminal khul jayega.


--------------------------------------------------------------------
STEP 2: IS FOLDER KI FILES CLOUD SHELL PE UPLOAD KARO
--------------------------------------------------------------------
Option A - Script use karo (recommended):
  Cloud Shell terminal me ye command chalao:

  bash start_heaven_os.sh

Option B - Manual commands (same as how to start up.txt):

  docker run -d --name=heaven-os -p 8888:3000 --shm-size="1gb" \
    -e TITLE=HeavenOS \
    lscr.io/linuxserver/webtop:arch-xfce

  (Image automatically download hogi aur background me launch ho jayegi)


--------------------------------------------------------------------
STEP 3: CLOUDFLARE TUNNEL DOWNLOAD KARO
--------------------------------------------------------------------
Public web link banane ke liye ye tool download karo:

  curl -L --output cloudflared https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 && chmod +x cloudflared


--------------------------------------------------------------------
STEP 4: PUBLIC LINK GENERATE KARO
--------------------------------------------------------------------
Ye command chalao:

  ./cloudflared tunnel --url http://localhost:8888

Output me 3-5 seconds ke andar ek aisi link dikhegi:
  https://xxxx-xxxx-xxxx.trycloudflare.com

Is link ko copy karo aur kisi bhi browser (Chrome/Edge/Phone) me open karo.
Tumhare samne full HeavenOS (Arch Linux XFCE) Desktop load ho jayega!

NOTE: Is terminal tab ko band mat karna, jab tak terminal khula hai
tab tak link chalegi.


--------------------------------------------------------------------
STEP 5 (FUTURE - EDITING): HEAVENOS CUSTOMIZE KARNA
--------------------------------------------------------------------
Agar HeavenOS me koi cheez change/edit karni hai:
1. Is folder ka Dockerfile edit karo (f:\PyeCloud\HeavenOS\Dockerfile)
2. Apni changes add karo
3. Cloud Shell pe build karo:
   docker build -t heaven-os .
   docker run -d --name=heaven-os -p 8888:3000 --shm-size="1gb" heaven-os


--------------------------------------------------------------------
HOW TO TURN OFF / SHUTDOWN
--------------------------------------------------------------------
1. Jis window me tunnel chal raha hai, wahan keyboard se dabao:
   Ctrl + C

2. Container stop aur delete karne ke liye command chalao:
   docker rm -f heaven-os

   Ya script chalao:
   bash stop_heaven_os.sh

Sab kuch clean aur stop ho jayega.
