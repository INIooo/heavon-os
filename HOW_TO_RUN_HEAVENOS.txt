====================================================================
     HEAVENOS CLOUD OS - COMPLETE STEP-BY-STEP STARTUP GUIDE
====================================================================

NOTE: Ye setup Google Cloud Shell ya kisi bhi Cloud Server pe chalega.
Local PC pe koi heavy file download karne ki zaroorat nahi hai.

HeavenOS Features:
- Base: Ubuntu XFCE (Ultra-stable, zero Wayland bugs)
- Theme: macOS Sonoma Dark UI (WhiteSur GTK & Icons, Traffic Light Window Controls)
- Dock: Animated Plank Dock at the bottom
- Audio: PulseAudio WebRTC sound streaming enabled for browser
- Branding: Custom browser tab title & favicon (HeavenOS Cloud Workstation ☁️)
- Wallpaper: Permanent Lotus Wallpaper (Default system wallpapers purged)
- Apps: Google Chrome, Discord, VS Code, Blender, GIMP, Audacity, VLC, FileZilla
- Multi-Tenant: Spin up isolated Cloud PCs for multiple clients with custom titles

--------------------------------------------------------------------
STEP 1: GOOGLE CLOUD SHELL OPEN KARO
--------------------------------------------------------------------
1. Browser me open karo: https://console.cloud.google.com/
2. Apna Google Account login karo.
3. Top-right bar me ">_" (Activate Cloud Shell) icon par click karo.
4. Terminal open ho jayega.

--------------------------------------------------------------------
STEP 2: HEAVENOS REPOSITORY CLONE & START KARO (SINGLE COMMAND)
--------------------------------------------------------------------
Terminal me ye single command paste karke Enter dabao:

cd ~ && docker rm -f heaven-os 2>/dev/null ; docker rmi heaven-os 2>/dev/null ; rm -rf heavon-os ; git clone https://github.com/INIooo/heavon-os.git && cd heavon-os && bash start_heaven_os.sh

(HeavenOS build ho kar Port 8888 par launch ho jayega!)

--------------------------------------------------------------------
STEP 3: MULTI-TENANT CLOUD PC MANAGEMENT (MULTIPLE CLIENTS)
--------------------------------------------------------------------
Agar alag-alag clients ke liye isolated Cloud PCs chalana chahte ho:

1. Naya Client Cloud PC Create Karo:
   bash create_client_pc.sh rahul 8888
   bash create_client_pc.sh amit 8889
   bash create_client_pc.sh client3 8890

2. Sabhi Active Clients List Karo:
   bash create_client_pc.sh list

3. Kisi Client PC ko Stop Karo:
   bash create_client_pc.sh stop rahul

4. Kisi Client PC ko Delete Karo:
   bash create_client_pc.sh delete rahul

5. Client PC ke liye Dedicated Public Link Launch Karo:
   bash create_client_pc.sh tunnel rahul

--------------------------------------------------------------------
STEP 4: PUBLIC WEB LINK GENERATE KARO (STANDALONE CLOUDFLARE TUNNEL)
--------------------------------------------------------------------
Agar default instance (Port 8888) ke liye public web link chahiye,
terminal me ye command run karo:

curl -L --output cloudflared https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64 && chmod +x cloudflared && ./cloudflared tunnel --url http://localhost:8888

Output me ek public link dikhegi:
  https://xxxx-xxxx.trycloudflare.com

Is link ko copy karke browser me kholo — macOS Sonoma Desktop khul jayega!

--------------------------------------------------------------------
STEP 5: HEAVENOS BAND / SHUTDOWN KAISE KAREIN
--------------------------------------------------------------------
1. Cloudflare tunnel band karne ke liye terminal me dabao:
   Ctrl + C

2. Container stop & delete karne ke liye command chalao:
   bash stop_heaven_os.sh
   (ya: docker rm -f heaven-os)
