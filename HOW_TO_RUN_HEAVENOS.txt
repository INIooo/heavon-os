====================================================================
         HeavenOS - HOW TO RUN (Ubuntu XFCE macOS Sonoma Edition)
====================================================================

NOTE: Ye poora setup Google Cloud Shell ya kisi bhi Linux server pe chalega.
HeavenOS = Ubuntu XFCE (LinuxServer Webtop) with macOS Sonoma Dark UI.

--------------------------------------------------------------------
STEP 1: LAUNCH HEAVENOS
--------------------------------------------------------------------
Terminal me ye command chalao:

  bash start_heaven_os.sh

Container automatically build ho kar port 8888 par start ho jayega.


--------------------------------------------------------------------
STEP 2: OPEN IN BROWSER
--------------------------------------------------------------------
Browser me access karo:
  http://localhost:8888  (Ya Web Preview port 8888)


--------------------------------------------------------------------
HOW TO TURN OFF / SHUTDOWN
--------------------------------------------------------------------
Container stop aur delete karne ke liye:

  bash stop_heaven_os.sh

Sab kuch clean aur stop ho jayega.
